# Lima Finance Hub

Portal de conteúdo sobre finanças, investimentos e educação financeira.

## 📊 Sobre o projeto

O Lima Finance Hub é um projeto web desenvolvido com o objetivo de reunir conteúdos relacionados ao universo financeiro, apresentando artigos e informações de forma organizada e acessível.

O projeto também foi estruturado com foco em boas práticas de desenvolvimento web, organização de conteúdo e otimização para mecanismos de busca.

## 🎯 Objetivos

- Produzir conteúdo sobre finanças e investimentos.
- Organizar os artigos por temas e categorias.
- Facilitar o acesso às informações financeiras.
- Desenvolver uma estrutura adequada para publicação de conteúdo na web.
- Aplicar técnicas de SEO para melhorar a indexação das páginas.

## 🛠️ Tecnologias e recursos

- HTML5
- CSS3
- JavaScript
- SEO
- Sitemap XML
- Robots.txt
- Meta tags
- URLs canônicas
- Open Graph
- Twitter Cards
- Google Search Console
- Google Analytics

## 📰 Conteúdo

O projeto conta com artigos relacionados a temas como:

- Investimentos
- Educação financeira
- Planejamento financeiro
- Reserva de emergência
- Mercado financeiro
- Organização financeira
